# Historical archive

The independent dyadic Bell ladder was archived on 2026-10-06 when `main`
was scoped to the current classification paper and supplementary information.

- Fixed tag: [`archive/dyadic-ladder-20261006`](https://github.com/xh-xihe/sslp-classification/tree/archive/dyadic-ladder-20261006)
- Archived commit: [`133f0e4b`](https://github.com/xh-xihe/sslp-classification/commit/133f0e4b27de8f077863908760d5421ddf2f7795)
- Preserved material: `code/`, `data/`, `lean/`, `paper/`, `results/`, and the original root environment and reproduction instructions.

Open the tag to browse or download the complete repository before cleanup.
To work with it locally, check out the tag in a separate clone. From that
historical checkout, follow its original `REPRODUCE.md`.

The archived dyadic package is independent from the active classification
acceptance. Its kernel result establishes distance at least three for the
order-8 seed family. The matching distance upper bound and additions in the
expanded research draft have separate certification requirements.

The archive remains publicly accessible if this repository is made public.
