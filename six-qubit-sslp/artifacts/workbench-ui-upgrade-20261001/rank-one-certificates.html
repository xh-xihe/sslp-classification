Scope and reproduction steps

The seven theorem roots were audited for transitive axioms: Classical.choice, Quot.sound and propext. This certificate does not establish an elementary-gate encoder, minimal gate order, classification exhaustiveness, or full manuscript coverage. New inputs do not inherit it.

Download the kit and follow its environment setup guide. With the pinned dependencies installed, run from the extracted bundle:

python tools/sslp_explorer.py check-bundle .
python tools/sslp_explorer.py verify case.json --lean --output fresh-run

The first command checks integrity. The second executes Lean and creates a fresh result. Save modified codewords in a separate candidate.json and use a new output directory for each verification.
