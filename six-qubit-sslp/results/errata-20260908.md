# Errata and counterexamples for the 20260908 manuscript

The authoritative TeX sources are unchanged. This file records discrepancies;
it does not silently replace a manuscript statement with a weaker theorem.

## Unqualified quantum Singleton bound

Location: `documents/20260908/main.tex`, `eq:quantum-Singleton` and its
immediately preceding scope statement.

**Author decision:** keep the main text unchanged for now; record the
counterexample and proposed erratum separately.

Under the manuscript's Knill–Laflamme detection definition, take the
three-qubit rank-one code spanned by the normalized vector `|000>`.
For every operator E, its rank-one projector P satisfies

    P E P = <000|E|000> P.

Consequently the code satisfies every finite detection-distance condition,
in particular the condition used by `ExactCode 3 1 3`. Substitution in the
unqualified Singleton inequality gives

    1 <= 2^(3 - 2*(3 - 1)) = 1/2,

which is false. The formal expression uses an integer exponent; natural-number
truncated subtraction would conceal the counterexample.

Kernel declarations in `MainTheory/SingletonRankOneCounterexample.lean`:

- `normalized`: normalization of the literal state;
- `detects_all_distances`: KL detection at every natural-number distance;
- `code`: an actual `ExactCode 3 1 3`;
- `violates_unrestricted_singleton`: negation of the literal inequality.

Compilation and the axiom audit passed. The last declaration depends only on
`propext`, `Classical.choice`, and `Quot.sound`; the audit is recorded in
`tmp/audit-20260908-changes.log`.

**Proposed erratum:** restore “For codes encoding nontrivial logical
information, K >= 2” before the bound. The existing
`MainTheory.QuantumSingleton.quantum_singleton` proves that qualified scope.
Changing the distance convention would instead require a separate revision
of definitions and all dependent statements, and is not assumed here.

**Certification consequence:** this assertion remains `partial` in
`paper-claims-20260908.json`. The manuscript as written cannot be certified
in full while this false unqualified statement is retained.

## Cited orbit-7 construction: gate convention mismatch

Location: `documents/20260908/supplementary.tex`, `eq:o7knowntransversal`.
The cited construction is Appendix B.1 of
[arXiv:2504.20847v1](https://arxiv.org/html/2504.20847v1).

The exact check uses the standard Pauli Y, Hadamard H, S = diag(1,i),
ordinary matrix multiplication, Z(t) = diag(exp(-it/2),exp(it/2)),
the literal five-qubit perfect-code vectors, the ancilla |0>, and

    V = A (X+Y) - B Z,
    A = sqrt((3-sqrt(3))/12), B = sqrt((3+sqrt(3))/6),
    U(theta) = CZ (V tensor Ry(theta)).

`MainTheory.CitedAncillaFamily` defines the resulting literal six-qubit
vectors. `endpoint` identifies theta = 0 with the actual five-qubit V-rotated
vectors tensored with |0>. `paper_gate_fails_at_zero` proves that applying
the displayed (Y H S) tensor power four, followed by Z(2pi/3) and I,
to the first vector does not yield a linear combination of the two vectors.
This is a failure of span preservation, not a numerical residual tolerance.

The exact integer certificates, complex-matrix interpretation, ancilla bridge
and final theorem compiled. Their axiom audit uses only the standard three
axioms (`tmp/audit-cited-ancilla.log`). This check does not assert that every
possible alternative convention for the cited construction fails.

**Candidate correction under investigation:** replace the S factor by
S-adjoint. `FiveQubitCorrectedGateData.corrected_checked` verifies a finite
integer identity for that candidate. `FiveQubitCorrectedGateSemantics.action`
now interprets it as the actual complex five-qubit gate action, and
`CitedCorrectedFamily.action` proves the corresponding six-qubit codeword
action for every real theta with a theta-independent logical matrix.
Both passed the standard-three-axiom audit
(`tmp/audit-five-qubit-corrected-gate-semantics.json`,
`tmp/audit-cited-corrected-family.json`). The associated normalized enumerator
parameter is now proved: `CitedConstructionAlpha.alpha` gives
`A1 = cos(theta)^2` for the literal constructed family, with normalization
and actual single-Pauli trace semantics; its six-root audit passed
(`tmp/audit-cited-construction-alpha.json`). The complete distance-three
construction and orbit presentation are still being closed; the candidate
must not yet be described as a certified replacement of the entire cited
argument. No TeX change is made.

`CitedCorrectedLogicalGate.logical_matrix` identifies the logical matrix as
one half of `[[-1+i,1+i],[-1+i,-1-i]]`; `logical_unitary` proves unitarity and
`recovered_word` proves the reverse span inclusion for every theta. These
three declarations passed `tmp/audit-cited-corrected-logical-gate.json`.

## Literal orbit-9 witness: displayed bit order needs clarification

Location: supplementary.tex, the two lists at `align*@3273`.
The exact amplitude, normalization and KL checks pass when each printed
binary word is read as an integer and coordinate one is its least significant
bit. This is the interpretation explicitly used in `Orbit9LiteralWitness`.
The new orbit-21 witness, in contrast, passes its stated fiber conditions with
coordinate one at the left of each printed ket.

There is a kernel-checked obstruction to silently reading the orbit-9 list
with coordinate one at the left. Its nonzero `000111` bottom-word coefficient
is `exp(i*pi/3)^2/sqrt(12)`. With the displayed angle `(1,1,1,1,1,2)`, that
left-to-right tuple has weight one modulo three, whereas the bottom fiber is
weight zero. `Orbit9LiteralBitConvention.weight_seven`,
`coefficient_seven_nonzero`, and `left_word_not_original_fiber` prove these
facts. The same word as a least-significant-coordinate-first integer has
weight zero, as required by the existing exact certificate.

This establishes a notation-dependent fiber mismatch, not a failure of the
underlying code or of the orbit classification. The CSV integer convention
near the end of the supplement does not by itself specify whether printed
ket strings are integer displays or coordinate tuples throughout the text.

**Suggested resolution:** explicitly state the per-table bit convention, or
adopt coordinate one on the left throughout and reverse every six-character
string in the orbit-9 witness list (leaving each phase and denominator
attached to its word). Until the manuscript convention is settled, its
literal-list assertion remains `partial`; the exact code certification under
the documented integer interpretation is retained. No TeX change is made.

The proposed word-reversal correction is now itself kernel checked:
`Orbit9CorrectedLiteralConvention.corrected_data` checks every coefficient,
`corrected_words` identifies the corrected left-coordinate words with the
existing exact realization, and `corrected_code` proves distance-three KL.
Its three declarations passed the standard-axiom closure audit
(`tmp/audit-orbit9-corrected-convention.json`). This certifies the concrete
candidate without deciding the manuscript's intended notation for the author.
