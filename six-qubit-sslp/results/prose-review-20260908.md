# Prose review of the 20260908 manuscripts

The claims ledger tracks every display and every named result. It does not
track running text. That gap matters: a sentence in a paragraph is where an
unformalized claim can sit indefinitely, because nothing in the pipeline
forces anyone to look at it. This is the separate review of those sentences.

Generated by `tools/prose_review_doc.py` from
`results/prose-review-20260908.json`. Edit the generator, never this file.

**No manuscript text appears here.** The sources are an unpublished
collaborator draft and are gitignored; assertions are identified by line
number and described in our own words.

## Method

Each source was split into chunks of about 500 lines. One agent read each chunk and classified every mathematically substantive prose assertion in it; a second agent re-read the same range, tried to refute each classification in both directions, and reported assertions the first had missed. 32 chunks, 64 agents, no failures.

Each assertion is classified as one of four kinds.

| kind | meaning |
| --- | --- |
| `gap` | a mathematical assertion with no Lean declaration behind it |
| `covered` | not carried by any tracked display or named result, but a declaration states it |
| `tracked` | restates or previews a display or named result the ledger already holds |
| `nonmath` | motivation, attribution, roadmap: nothing to certify |

The standard for `covered` is the ledger's: a declaration must carry the
*whole* assertion. Prose often quantifies more broadly than any single
theorem -- "in all cases", "the same argument applies" -- and where the Lean
has the instances but not the general statement, that is a `gap`.
