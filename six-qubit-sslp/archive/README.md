# Historical material

This directory preserves superseded material outside the active proof libraries.

- `stages/`: the old beta-five and beta-six construction trees, moved without
  changing file contents. Current certificates live in `MainTheory/Generated/`.
- `documentation/`: earlier README snapshots and their historical progress counts.
- `reviews/20261003-pre-structure/`: records bound to the SI before the
  2026-10-04 structural edit. They remain evidence for that source snapshot.

Archive contents are not included in the current default Lean build or source
gate. Current entry points are listed in [docs/proof-index.md](../docs/proof-index.md).
Historical coverage is retained here; it is not automatically assigned to a
changed manuscript. Source hashes and review candidates allow it to be revisited.
